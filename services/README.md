# services

This folder contains the main service files for the application features.

## Files

- `speaker_service.py`  
  Will handle functionality related to viewing speakers and sessions.

- `attendee_service.py`  
  Will handle functionality related to viewing attendees by company and adding new attendees.

- `connection_service.py`  
  Will handle functionality related to attendee connections using Neo4j.

- `room_service.py`  
  Handles functionality related to viewing rooms.

## Purpose

The purpose of this folder is to keep the application logic organised by feature, instead of placing all code inside `main.py`.
