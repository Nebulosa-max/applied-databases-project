# Applied Databases Project

Final project for the Applied Databases module.

## Project Overview
This project is a Python-based conference management application using:
- MySQL
- Neo4j

The application allows the user to:
- View speakers and sessions
- View attendees by company
- Add a new attendee
- View connected attendees
- Add attendee connections
- View rooms
