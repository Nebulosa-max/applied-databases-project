# db

This folder contains the database connection files used by the application.

## Files

- `mysql_connection.py`  
  Handles the connection between the Python application and the MySQL database.

- `neo4j_connection.py`  
  Handles the connection between the Python application and the Neo4j graph database.

## Purpose

The purpose of this folder is to keep database connection logic separate from the main program and from the application features.
